# kaze_well 🛡️

جدار ناري لأندرويد مكتوب بـ **Kotlin** و **Jetpack Compose**. يقطع الإنترنت عن كل التطبيقات، ويعمل الإنترنت فقط للتطبيقات التي تسمح لها.
Android firewall written in Kotlin: every app is offline unless you allow it.

## كيف يعمل (بدون روت)
يستخدم `VpnService` محلياً. كل تطبيق **غير مسموح** يُوجَّه إلى نفق افتراضي لا يُمرّر الحزم إلى أي مكان، فيبقى بلا إنترنت. أما التطبيقات المسموحة فلا تدخل النفق أصلاً، فتعمل بسرعتها الطبيعية دون وسيط. لا يخرج أي شيء من جهازك، والتطبيق نفسه لا يطلب صلاحية الإنترنت.

## المميزات
- زر تشغيل/إيقاف بدرع متحرك، وعدّاد للحزم المحجوبة.
- قائمة بكل التطبيقات التي تطلب إنترنت، مع بحث وفلاتر: الكل / تطبيقاتي / النظام / المسموح / المحجوب.
- مفتاح لكل تطبيق، وأزرار «السماح للظاهر» و«حجب الظاهر».
- التطبيقات الجديدة التي تُثبَّت تُحجب تلقائياً.
- التشغيل التلقائي بعد إقلاع الجهاز.
- واجهة بالعربية والإنجليزية (حسب لغة الجهاز) مع دعم RTL.

## البناء عبر GitHub
1. ارفع محتوى هذا المجلد إلى مستودع جديد (مع `.github`).
2. افتح **Actions** ← **Build kaze_well APK** ← *Run workflow* (أو يعمل تلقائياً عند كل push).
3. حمّل الـ APK من **Artifacts**.

## ملاحظات مهمة
- أندرويد يسمح بـ **VPN واحد فقط** في نفس الوقت، فلن يعمل kaze_well مع تطبيق VPN آخر.
- لضمان عدم توقف الجدار: الإعدادات ← الشبكة ← VPN ← kaze_well ← فعّل **Always-on VPN**.
- حجب تطبيقات النظام (مثل خدمات Google Play) قد يعطّل الإشعارات والتحديثات، فاسمح لها إن لزم.
- الصلاحية `QUERY_ALL_PACKAGES` مطلوبة لعرض كل التطبيقات، وهي مقبولة للتثبيت المباشر لكن Google Play يقيّدها.
- نسخة release موقَّعة بمفتاح debug للتجربة؛ بدّله بمفتاحك قبل النشر.
